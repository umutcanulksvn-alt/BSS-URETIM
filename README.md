# Üretim Makine Kontrol

Üretim makinelerinin durumlarını takip etmek için hazırlanmış web uygulaması.

## Özellikler

- Makine ekleme
- Makine silme
- Makine düzenleme
- Makine sıralama
- Durum seçenekleri ekleme
- Durum seçenekleri silme
- Durum seçeneklerini düzenleme
- Bir makinede birden fazla durum seçme
- Günlük iş/durum sıfırlama
- A4 PDF raporu oluşturma
- Telefon ve bilgisayar uyumlu arayüz

## Makineler

B1, B13, B2, B3, B12, B4, BT1, B5, B6, B7, BT2, BT3, BT4, BT5, B8, B9, B10, B11, T1, T2, T3, T4, T5

## Kullanım

Uygulama `index.html` üzerinden çalışır ve GitHub Pages ile yayınlanabilir.
